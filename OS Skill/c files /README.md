OS Shell Project – System Programming & Shell Skills

This repository contains the C programs developed for OS Shell and System Programming practicals (Skills 1–24). The programs demonstrate important Linux concepts such as command parsing, process creation, pipes, redirection, background jobs, signals, process groups, memory management, testing, and shell execution.

📌 Topics Covered
Command Parsing and Tokenization
Command History
Quotes and Escape Sequences
fork(), exec(), and waitpid()
PATH Resolution
Environment Variables and Built-in Commands
Pipes and Multiple Pipelines
Input, Output, Append and stderr Redirection
Combined and Complex Redirection
Background Jobs
Job Tables and Job Control
Foreground and Background Process Management
Signal Handling
SIGINT and SIGTSTP
Process Groups
Error Handling
Memory Management and Valgrind
Automated Testing
Large Pipelines
System Calls
Shell Project Validation and Final Demonstration


System Calls: fork(), exec(), waitpid(), pipe(), dup2(), open(), close(), kill()


▶️ How to Compile and Run

Compile any program using:

gcc skill17a.c -o skill17a

Run:

./skill17a

For example:
gcc skill23a.c -o skill23a
./skill23a
